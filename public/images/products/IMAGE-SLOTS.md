# Blind images

Add your real photographs here. Use the following names for each of `roller`, `roman`, and `venetian`:

- `roller-main.webp`: collection image and detail hero (wide room view).
- `roller-detail-01.webp`: room setting.
- `roller-detail-02.webp`: fabric/material close-up.
- `roller-detail-03.webp`: finishing detail or a second angle.
- `roller-compare.webp`: reference image for the "collection at a glance" comparison card on /blinds (4:3 crop showing the shape of the blind).

Repeat with `double-roller`, `roman`, `honeycomb`, `venetian`, `vertical` and `panel`. Run `npm run images` after adding files, or restart development. Rebuild for production. See `/IMAGE_GUIDE.md` at the project root for the complete checklist.
